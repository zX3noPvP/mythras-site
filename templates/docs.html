  • {{ _("language: en, it, es, pt, de, fr, pl or zh (or change it in game with /ac lang <code>).")|safe }}

  • {{ _("alerts: alerts in chat and console, cooldown-ms, click-command.")|safe }}

  • {{ _("checks.<name>: every check has:")|safe }}
    • enabled;
    • {{ _("buffer: how many proofs are needed before a flag (higher = fewer false flags);")|safe }}
    • {{ _("vl-weight and vl-decay-per-second;")|safe }}
    • {{ _("punish-vl: VL that runs the punishment, 0 = alerts only (Pro);")|safe }}
    • {{ _("punish-commands: punishment commands for this check only (Pro).")|safe }}
  • {{ _("punishments.commands (Pro): [kick] <message>, [message] <text> or any console command, for example ban %player% 7d Cheating. Placeholders: %player%, %check%, %vl%, %kick-message%.")|safe }}
  • {{ _("setback (Pro): pulls the cheater back to the last valid position.")|safe }}
  • {{ _("discord (Pro): webhook for alerts and punishments. ai-suspects (Pro): new AI suspects (85%+) with the reason.")|safe }}
  • {{ _("mitigations: (Pro) cancels impossible hits, halves damage after combat flags, health filter; with the add-ons, on any plan:")|safe }}
    • {{ _("anti-esp and anti-storage-esp (Anti-ESP add-on, any plan): containers the player cannot see are sent as the block next to them, so StorageESP/ChestESP show nothing behind walls (blocks = which containers);")|safe }}
    • {{ _("anti-xray (Anti-XRay add-on, any plan): ores out of sight are sent as rock, also those open to caves, until the player can see them (blocks, max-y, max-distance). It replaces Paper's anti-xray, which you can leave off.")|safe }}
    • {{ _("Anti-ESP works on its own thread, so it costs almost nothing on the main thread. Walls changed by commands or WorldEdit (no block event) are noticed within 3 seconds; walls broken, placed or blown up by players at once.") }}
  • {{ _("replay (Pro): mode: flag records flagged players, mode: always keeps the last 25 seconds of everyone. Replays are kept 7 days, then deleted.")|safe }}
  • {{ _("ai (Pro): self-learning model; tune it and train it with staff labels (/ac ai label).")|safe }} {{ _("ai.cloud (Pro): Mythras Cloud AI, enabled and share (see Plans).")|safe }}
  • {{ _("checks.freecam (Pro): clicks on blocks hidden behind walls (FreeCam, GhostHand) are refused with cancel: true (a chest behind a wall stays closed) and flagged.")|safe }}
  • {{ _("checks.xray (Pro): min-veins, max-stone-per-vein, window-minutes, ores. Alerts only by default: check the player's replay before punishing. Paper's anti-xray (engine-mode: 2 in paper-world-defaults.yml) works well together with it.")|safe }}
  • {{ _("network (Pro): alerts of all servers behind BungeeCord/Velocity. With MythrasProxy (below) set network.proxy-plugin: true.")|safe }}
