What is shared: 20 numbers per 20 hits (click speed and rhythm, how the view turns, reach, hit ratio, aim steadiness...) and whether the player was punished, never names, UUIDs or IP addresses. ai.cloud.share: false only downloads the model, ai.cloud.enabled: false turns it off. /ac ai status shows the global model.")|safe }}

{{ _("7. Configuration") }}

{{ _("Files in plugins/Mythras/:")|safe }}

  • {{ _("config.yml: contains only the options of your plan. After an upgrade the new options are added at the end.")|safe }}
  • {{ _("messages_<code>.yml: all texts, hex colours and gradients supported, in 8 languages (en, it, es, pt, de, fr, pl, zh). Choose with /ac lang <code> or language: en.")|safe }}

{{ _("Main options") }}

  • {{ _("language: en, it, es, pt, de, fr, pl or zh (or change it in game with /ac lang <code>).")|safe }}
  • {{ _("database.type: file (default), sqlite, mysql, mongodb. If the connection fails Mythras falls back to file.")|safe }}
  • {{ _("alerts: alerts in chat and console, cooldown-ms, click-command.")|safe }}
  • {{ _("exemptions (Pro+): whitelist and exemptions. players (names or UUIDs), worlds and WorldGuard regions where no check runs (staff, minigames, launch pads).")|safe }}
  • {{ _("bedrock: checks used on Bedrock players (Geyser).")|safe }}
  • {{ _("checks.<name>: every check has:")|safe }}
    • enabled;
    • {{ _("buffer: how many proofs are needed before a flag (higher = fewer false flags);")|safe }}
    • {{ _("vl-weight and vl-decay-per-second;")|safe }}
    • {{ _("punish-vl: VL that runs the punishment, 0 = alerts only (Base+);")|safe }}
    • {{ _("punish-commands: punishment commands for this check only (Base+).")|safe }}
  • {{ _("punishments.commands (Base+): [kick] <message>, [message] <text> or any console command, for example ban %player% 7d Cheating. Placeholders: %player%, %check%, %vl%, %kick-message%.")|safe }}
  • {{ _("setback (Base+): pulls the cheater back to the last valid position.")|safe }}
  • {{ _("discord (Base+): webhook for alerts and punishments.")|safe }}
  • {{ _("mitigations (Pro+): cancels impossible hits, halves damage after combat flags, health filter, Anti-ESP, and")|safe }}
    • {{ _("anti-storage-esp: containers the player cannot see are sent as the block next to them, so StorageESP/ChestESP show nothing behind walls (blocks = which containers);")|safe }}
    • {{ _("anti-xray: ores out of sight are sent as rock, also those open to caves, until the player can see them (blocks, max-y, max-distance). It replaces Paper's anti-xray, which you can leave off.")|safe }}
    • {{ _("Anti-ESP works on its own thread, so it costs almost nothing on the main thread. Walls changed by commands or WorldEdit (no block event) are noticed within 3 seconds; walls broken, placed or blown up by players at once.") }}
  • {{ _("replay (Pro+): mode: flag records flagged players, mode: always keeps the last 25 seconds of everyone. keep-days: how long replays are kept (at most 7 days: older ones are deleted).")|safe }}
  • {{ _("ai (Pro+): self-learning model. Enterprise can also tune it and train it with staff labels (/ac ai label).")|safe }} {{ _("ai.cloud (Enterprise): Mythras Cloud AI, enabled and share (see Plans).")|safe }}
  • {{ _("checks.freecam (Base+): clicks on blocks hidden behind walls (FreeCam, GhostHand) are refused with cancel: true (a chest behind a wall stays closed) and flagged.")|safe }}
  • {{ _("checks.xray (Base+): min-veins, max-stone-per-vein, window-minutes, ores. Alerts only by default: check the player's replay before punishing. Paper's anti-xray (engine-mode: 2 in paper-world-defaults.yml) works well together with it.")|safe }}
  • {{ _("network (Enterprise): alerts of all servers behind BungeeCord/Velocity.")|safe }}
